# Diretrizes de identidade visual — Sistema Bancário

## Conceito

Identidade banking corporate, institucional e sóbria. O emblema utiliza a arquitetura clássica de uma instituição financeira para representar estabilidade, organização e confiança.

## Paleta aplicada

| Token | HEX | Aplicação |
| --- | --- | --- |
| Azul-marinho | `#0A2038` | Fundo principal |
| Azul institucional | `#123655` | Superfícies e profundidade |
| Prata | `#CBD5E1` | Emblema e linhas arquitetônicas |
| Azul de apoio | `#3A91CF` | Acentos e elementos gráficos |
| Branco | `#F7FAFC` | Texto e contraste |

## Ativos oficiais

- `assets/brand/logo.svg`: emblema vetorial com fachada institucional.
- `assets/brand/banner.svg`: banner horizontal editorial para README e apresentações.
- `assets/brand/project-mark.svg`: marca anterior preservada para compatibilidade.

## Aplicação

Preservar proporções, contraste e área de respiro. Utilizar os SVGs locais do repositório e não alterar individualmente as cores dos ativos.
