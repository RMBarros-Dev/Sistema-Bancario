# Política de segurança

## Escopo

Mantenho o Sistema Bancário como projeto educacional. Considero relevantes falhas em validação de operações, controle de saldo, persistência, configuração, dependências e exposição de dados.

## Como reporto ou recebo relatos

Peço que não sejam publicados detalhes de vulnerabilidades em Issues públicas. Quando disponível, utilizo **Report a vulnerability** na aba Security do GitHub. Como alternativa, mantenho contato privado pelo e-mail cienciadacomputacaorenan@gmail.com.

## Versões suportadas

Prioritizo a branch padrão `master`. Não declaro suporte a versões antigas sem uma release correspondente.

## Limite de uso

O projeto é uma simulação educacional e não deve ser utilizado para movimentar dinheiro ou armazenar dados financeiros reais.

## Tratamento

Analiso o relato, procuro reproduzir o problema e documento a correção quando estiver concluída.
